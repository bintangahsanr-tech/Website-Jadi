# Robot Controller
Micro:bit adalah komputer mini untuk belajar teknologi, pemrograman, dan elektronika dengan cara menyenangkan. Dilengkapi LED, tombol, dan sensor, micro:bit dapat digunakan untuk membuat berbagai proyek kreatif. Selain belajar coding, micro:bit juga melatih kreativitas, logika, dan kemampuan memecahkan masalah.
